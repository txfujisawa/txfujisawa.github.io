# Academic Website / 研究者ウェブサイト

GitHub Pages向けの静的サイトです。

## ファイル
- `index.html`: トップページ
- `research.html`: Researchページ
- `style.css`: デザイン
- `script.js`: 日本語・英語切り替え（ブラウザに選択を保存）

## 公開方法
1. 4ファイルをGitHubリポジトリのルートにアップロードします（既存の `index.html` は置き換え）。
2. Settings → Pages → Deploy from a branch → main / (root) → Save。
3. `https://ユーザー名.github.io/リポジトリ名/` を開きます。

公開前にプロフィール、所属、研究内容、連絡先等を確認してください。外部の画像・フォント・JavaScriptライブラリには依存しません。
